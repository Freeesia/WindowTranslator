# BluePrinceOcr

Blue Prince の手紙などの英文を、行ではなく段落ごとの TextRect として返す OCR プラグインです。OCR モジュールで **BluPrinceOcr** を選び、原文言語を英語に設定してください。

OneOcr と同じ Windows の Snipping Tool の認識エンジンを使用します。初回の検証で必要な DLL とモデルを共通の OneOcr ディレクトリへ配置します。OneOcr プラグイン自体のインストールは不要です。ビルド時には隣の OneOcrPlugin のネイティブ定義、セットアップ用ユーティリティ、翻訳済みリソースを共有ソースとして取り込みます。

認識行の角度を補正してから、同じ列・向き・文字サイズの行について通常の行送りを推定します。文字高で正規化した直下行までの距離を収集し、短い側の半分の中央値を通常の行送りとします。段落間の広い空白の影響を抑え、通常の行送りに許容倍率を掛けた距離を超えた箇所で分割します。段落内の行は空白で連結します。段落の矩形は回転を保持し、MultiLine と平均文字サイズを設定します。画像の固定座標や本文文字列には依存しません。画像の拡大率、明るさ、コントラスト、OCR 対象範囲は共通 OCR 設定を使用します。段落判定は専用の基準を使用するため、共通の結合しきい値は適用されません。

背後の紙や画面の UI も OCR で認識される場合があります。本文だけを翻訳したい場合は、共通 OCR 設定の対象範囲を指定してください。行間が非常に広い段落、段落間の余白がない文章、大きな字下げでは分割結果が変わることがあります。


## 段落判定の設定

対象アプリのプラグイン設定にある **BluPrinceOcr → 段落内の行送り許容倍率** で調整します。既定値は **1.45**、設定範囲は **1.05～2.50** です。

- 別の段落が結合される場合は倍率を下げます。
- 同じ段落の行が分割される場合は倍率を上げます。

文字高と行送りの比を使うため、解像度や画像拡大率に追従します。ただし、段落間と段落内の行送りが同じ文章や、比較できる行が少ない画像では自動判定に限界があります。原文が OCR の時点で一つの行として認識された場合は、その内部を段落に分割しません。

## 大見出しやアイコンを含む説明文

**文字サイズ差の許容率**（既定値 **0.30**、範囲 **0～2.00**）で、異なる文字高の行を結合できるようにします。値は大小の高さの差を小さい方の高さで割った比です。アイコンも行の高さに含まれるため、そのような行が分断される場合にも調整できます。

足跡アイコン入りの Blue Prince の説明画面では、**段落内の行送り許容倍率 1.90／文字サイズ差の許容率 1.20** で、大小の見出しを結合し、本文の 2 段落を別々に認識できることを確認しています。対象アプリごとの設定のため、同じゲームの通常の手紙まで結合される場合は、通常の手紙を読む際に既定値 **1.45／0.30** に戻してください。

この設定は段落の結合に作用します。手書き風の Y が T や F、足跡が !! として認識されるなど、OCR エンジン自体の誤認識を修正するものではありません。

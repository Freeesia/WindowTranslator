# WindowTranslator Sarashina3 Translator Plugin

## ja

[WindowTranslator](https://github.com/Freeesia/WindowTranslator)で、Sarashina3の翻訳APIを利用する翻訳プラグインです。

- Sarashina3 translate APIを利用した翻訳
- 翻訳APIキー、翻訳コンテキスト、用語集に対応
- 翻訳にはインターネット接続が必要です。翻訳対象のテキストはSarashina APIに送信されます。

Sarashina APIの利用登録とAPIキーの取得については、[Sarashina](https://sarashina.ai/)を確認してください。

## en

A [WindowTranslator](https://github.com/Freeesia/WindowTranslator) translation plugin that uses the Sarashina3 translation API.

- Translates with the Sarashina3 translate API
- Supports an API key, translation context, and glossary
- An internet connection is required. Text to translate is sent to the Sarashina API.

See [Sarashina](https://sarashina.ai/) to register and obtain an API key.
